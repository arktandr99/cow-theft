SOUNDS FUER COW THEFT
=====================

Alle Audiodateien in diesem Ordner werden vom Server ausgeliefert und vom Spiel
automatisch erkannt (Server neu starten, wenn du Dateien hinzufuegst/umbenennst,
dann im Browser Strg+F5). Fehlt eine Datei, spielt das Spiel einen synthetischen Ton.


1) FESTE DATEIEN (deine eigenen)
--------------------------------

reload.mp3                       Magazinwechsel (nur noch Reserve)
cow-mooing-sound-effect.mp3      Kuh
sound-of-a-cow-mooing.mp3        Kuh


2) AUTOMATISCH ERKANNTE GRUPPEN
-------------------------------
Eine Datei gehoert zu einer Gruppe, wenn ihr Name so beginnt (Endung egal:
.wav, .mp3 oder .ogg). Mehrere Dateien einer Gruppe = Varianten, das Spiel
waehlt zufaellig. Beispiele: shot_m4a1_1.mp3, imp_dirt_1.wav, imp_dirt_2.wav
Gehoeren zwei Gruppennamen zu einer Datei (shot_bolt und shot_bolt338), gewinnt der laengere.

WAFFEN (46 Waffen):
  shot_<waffe>     Schuss genau dieser Waffe, zum Beispiel shot_ak74_1.mp3
                   (hat Vorrang vor allem anderen; <waffe> = Waffen-ID, siehe Liste unten)
  shot_<klasse>    Schuss der Klangklasse (nur Reserve), zum Beispiel shot_r556_1.mp3
  reload_<waffe>   Nachladen genau dieser Waffe (mitgeliefert: reload_deagle, reload_mr73)
  reload_<klasse>  Nachladen der Klangklasse (siehe Tabelle)
  (Reihenfolge: Waffe -> Klasse -> alte Rollen-Namen -> synthetischer Ton)

  dry          Leerschuss (Abzug ohne Munition)               mitgeliefert: dry_1..7
  shellin      Patrone/Schrotpatrone wird eingelegt           mitgeliefert: shellin_1..5

  switch       Waffenwechsel                                  keine Datei -> synthetisch

Nachladen (reload_<klasse>.mp3, reload_deagle, reload_mr73): aus echten Einzelgeraeuschen der Bibliothek
zusammengesetzt - Magazin raus, Magazin rein, Verschluss/Schlitten (AR-15, AK-47, Colt 1911, Walther PPQ,
Carl Gustav, Tikka T3, S&W 642). Das Tempo passt das Spiel automatisch an die Nachladezeit an.
Leerschuss, Patrone einlegen, Repetieren, Pumpen: ebenfalls echte Einzelgeraeusche (1911, Mosin, Savage,
Tikka, Mossberg, Winchester, Charles Daly, Carl Gustav, PPSh).

Durchladen beim Nachladen: Ist noch eine Patrone im Lauf, wird nur das Magazin gewechselt (kuerzer). Ist die Waffe leergeschossen,
kommt am Ende das Durchladen dazu (Spannhebel / Schlitten): dafuer spielt das Spiel nach dem Magazingeraeusch eine Verschluss-
Aufnahme (bolt_1..4, bei Pistolen zwei synthetische Klicks) passend zugeschnitten ab. Eigene Dateien sind dafuer nicht noetig.

Die alten Klassen-Schussdateien shot_<klasse>_N.mp3 (z. B. shot_r556_1.mp3) werden nicht mehr benoetigt
und koennen geloescht werden; ebenso shot_sturm/scharf/hirte (alte Rollennamen).

5) UMGEBUNGSGERAEUSCHE (Voegel, Grillen)
----------------------------------------------
Werden direkt im Spiel erzeugt (keine Dateien noetig): Gezwitscher aus verschiedenen
Richtungen in Baumhoehe, selten Kuckuck und Kraehe und Grillen im Gras (kein Wind).
Bei Schuessen in der Naehe verstummen die Voegel einige Sekunden. Die Lautstaerke
steht im Code (AMB_BIRD_GAP = Pausen, in chirp() die Gesamtlautstaerke).

6) GRANATEN
----------------------------------------------
grenade-explosion-14-190266.mp3  -> Explosion der Splittergranate (Schalllaufzeit nach Entfernung,
                                    ferne Explosionen etwas dumpfer)
gas-grenade-95255.mp3            -> Rauchgranate (Plopp und Zischen, ca. 8 s)
Die Dateinamen stehen oben im Code (SAMPLE_FILES: boom und gas). Fehlt eine Datei, spielt
das Spiel den synthetischen Ersatzton.

Grenade Pin Tossed Into Leaves.mp3 -> Sicherungsstift ziehen: spielt sofort, sobald G gedrueckt wird
                                    (Granate "kochen"). Fehlt die Datei, klickt ein synthetischer Ersatz.
                                    Der Zuender laeuft ab dem Stiftziehen (3,6 s). Loslassen = werfen.

7) GLAS (Fenster in Wohnhaeusern)
----------------------------------------------
Fenster sind offen/durchsichtig: Man sieht und schiesst hindurch. Die Glasscheibe geht beim
ersten Treffer (Kugel, Granate, Explosion in <10 m) kaputt; die Kugel fliegt weiter.
Ohne Dateien klirrt ein synthetischer Ton. Eigene Geraeusche: Dateien glass_1.mp3, glass_2.mp3 ...
(oder .wav) in diesen Ordner legen, Server neu starten, Browser Strg+F5.
Scherben liegen nur als Effekt; zerbrochenes Glas bleibt bis zur naechsten Runde/Karte kaputt.

8) SONSTIGES (neu)
----------------------------------------------
Q beim Sanitaeter laesst ein Medkit fallen, Q beim MG-Schuetzen eine Munitionskiste (aufnehmbar).
Quad: Gegner ab ca. 25 km/h ueberfahren (Schaden steigt mit Tempo, ab ca. 42 km/h toedlich).
